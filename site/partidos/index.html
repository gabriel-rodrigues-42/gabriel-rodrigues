Perguntas frequentes

Como a conta é feita?

Para cada votação, a página vê quantos deputados de cada partido votaram Sim e quantos votaram Não. Se 80 de 100 votaram Sim e você respondeu Sim, o acordo naquela votação é de 80%. Se você respondeu Não, é de 20%. A nota do partido é a média das votações que você respondeu.

Abstenção, obstrução e ausência não entram na conta. Partido com menos de 3 deputados votando numa votação fica de fora dela.

De onde vêm os votos?

Da API de Dados Abertos da Câmara dos Deputados, que registra o voto de cada deputado em cada votação nominal, com o partido dele no dia. Cada pergunta tem o link da proposta no site da Câmara.

Por que essas dez votações?

São votações nominais de Plenário sobre temas que mexem com a vida de muita gente: imposto, gasto público, segurança, meio ambiente, redes sociais e regras para os próprios deputados. Escolhemos votações em que os partidos se dividiram, porque é aí que dá para ver diferença. A do Imposto de Renda foi quase unânime e ficou para mostrar que também há consenso.

Faltam temas importantes que ainda não tiveram votação nominal no Plenário, como regulação da cannabis e cartório digital. Quer sugerir outra votação? Abra uma issue no GitHub com o link dela.

Quais são os limites?
  • Mostra como os deputados votaram, não o que cada partido promete, nem como votariam hoje.
  • Partidos mudam. Deputado troca de partido, e partidos se fundem (o PTB e o Patriota viraram PRD; o PSC entrou no Podemos). A conta usa o partido do deputado no dia da votação, com o nome atual.
  • Urgência não é aprovação. Em duas perguntas a votação foi só sobre votar o projeto com pressa.
  • O resultado vale para a Câmara dos Deputados de 2023 a 2027. Câmara de vereadores e Assembleia votam outras coisas.
Minhas respostas vão para algum lugar?

Não. Tudo acontece no seu navegador. As respostas ficam só no endereço da página (depois do #). Ninguém conta quantas pessoas escolheram cada partido.

Como conferir o código?
  • scripts/partidos/gerar_votacoes.py: busca as votações na API da Câmara e conta os votos.
  • .github/workflows/dados-partidos.yml: roda o script no GitHub, com registro público.
  • site/partidos/dados/votacoes.json: os votos contados, partido por partido.
  • site/partidos/temas.js: o texto de cada pergunta.
Por que esta página existe?

Para escolher em quem votar, ou em qual partido entrar, ajuda saber como cada partido vota de verdade. O Gabriel não é filiado a nenhum partido e não usa esta página para indicar um. A ferramenta serve para qualquer pessoa.
