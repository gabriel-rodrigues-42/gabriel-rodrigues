# gabriel-rodrigues

Site, design system e projetos de Gabriel Rodrigues: um desenvolvedor de Inhumas (GO) que quer melhorar os sistemas do Brasil com mentalidade de engenharia de software.

Este repositório vai reunir:

- **site/**: o site gabriel-rodrigues.com
- **design-system/**: cores do Brasil e formas orgânicas, usado no site e nas animações
- **videos/**: roteiros e arquivos de edição dos vídeos do canal
- **projetos/**: descrições de projetos em HTML para consulta e referência
